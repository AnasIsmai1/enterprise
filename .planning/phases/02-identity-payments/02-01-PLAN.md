<objective>
Replace the boilerplate passport-jwt auth module with Better-Auth, configure email/password registration with verification, Apple and Google social login for mobile, JWT access/refresh token generation, login rate limiting, and 2FA for admin.

Purpose: Every subsequent feature depends on user identity. Better-Auth provides authentication (email, social, 2FA) while the existing AuthService provides JWT tokens for mobile clients. This plan establishes the auth foundation.

Output: Working auth system where users can register, verify email, log in (email/social), receive JWT tokens, refresh tokens, reset passwords, and where admins can enable 2FA.
</objective>

    **Step 1: Create LoginAttemptsService (src/modules/auth/application/services/login-attempts.service.ts)**
    Injectable service with `@Inject('REDIS_CLIENT')` Redis client:

    - `async checkAndIncrement(ip: string): Promise<void>` — AUTH-11: 5 failures per 15 min per IP, then 30-min lockout
      - Check `login_lockout:{ip}` key exists in Redis — if yes, throw `TooManyRequestsException('Account locked for 30 minutes')`
      - `INCR` the `login_failures:{ip}` key
      - If counter === 1, set `EXPIRE` to 900 seconds (15 min window)
      - If counter >= 5, set `login_lockout:{ip}` with `SETEX` 1800 seconds (30 min lockout)

    - `async clearFailures(ip: string): Promise<void>` — Clear failure counter on successful login
      - `DEL` both `login_failures:{ip}` and `login_lockout:{ip}`

    NOTE: The exact hook mechanism depends on `@thallesp/nestjs-better-auth`'s hook API. If the adapter supports `@Hook('before', 'signIn')` decorators, use those.
