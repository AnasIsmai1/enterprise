      @IsString()

    }

    **Step 2: Extend UserService (src/modules/user/application/services/user.service.ts)**

    Add or update methods:

    - `async getProfile(userId: string)`: Return user profile excluding password. Include `has_pet` boolean and `deletion_pending` status.
    - `async updateProfile(userId: string, dto: UpdateProfileDto)`: Update allowed fields (firstName, lastName, email, timezone). If email changes, mark `emailVerified = false` and trigger new verification email via EmailService.
    - `async initiateDeletion(userId: string)`: Set `deletionScheduledAt` to `now() + 14 days`. Send `EmailType.ACCOUNT_DELETION` confirmation email. Log via AuditLogService.
    - `async cancelDeletion(userId: string)`: Set `deletionScheduledAt = null`. Log via AuditLogService. Return confirmation.
    - `async acknowledgeHealthDisclaimer(userId: string)`: Set `healthDisclaimerAcknowledged = true` and `healthDisclaimerAcknowledgedAt = new Date()`.
    - `async validateAge(birthdate: Date, region?: string): boolean`: USER-06 enforcement — 13+ for US/OTHER, 16+ for EU. Calculate age from birthdate. Region is optional (default to 13+).

    **Step 3: Build UserController endpoints (src/modules/user/presentation/controllers/user.controller.ts)**

    All endpoints require authentication (the global Better-Auth AuthGuard handles this after Plan 01). Use `@CurrentUser()` or `@Session()` decorator from Plan 01 to get the authenticated user.

    Endpoints:
    - `GET /v1/users/me` — Returns full user profile. Response includes: id, email, firstName, lastName, avatarUrl, timezone, role, activePetId, healthDisclaimerAcknowledged, deletionScheduledAt (if set), created_at. Excludes password.
    - `PUT /v1/users/me` — Update profile fields (USER-05). Body: UpdateProfileDto. Returns updated profile.
    - `DELETE /v1/users/me` — Initiate account deletion (USER-02). Body: InitiateDeletionDto (must type 'DELETE'). Sets `deletionScheduledAt` to 14 days from now. Response: `{ message: 'Account deletion scheduled', deletion_date: '...' }`.
    - `POST /v1/users/me/restore` — Cancel account deletion during grace period. Clears `deletionScheduledAt`. Response: `{ message: 'Account deletion cancelled' }`. Throw 400 if no deletion is scheduled.
    - `POST /v1/users/me/acknowledge-disclaimer` — Track health disclaimer acknowledgment (USER-04). Response: `{ acknowledged: true, acknowledged_at: '...' }`.
