    **Step 3: Create HasPetGuard (src/common/guards/has-pet.guard.ts)**

    LOCKED DECISION: "Pet creation is mandatory immediately after registration -- the app is meaningless without a pet, so the backend should enforce at least one pet exists before granting full access."

    Create a global NestJS guard that enforces mandatory pet onboarding:

    ```typescript
    @Injectable()
    export class HasPetGuard implements CanActivate {
      constructor(
        private petService: PetService,
        private reflector: Reflector,
      ) {}

      async canActivate(context: ExecutionContext): Promise<boolean> {
        // Skip if route is marked as bypassing the pet check
        const skipPetCheck = this.reflector.getAllAndOverride<boolean>(
          'SKIP_PET_CHECK',
          [context.getHandler(), context.getClass()],
        );
        if (skipPetCheck) return true;

        const request = context.switchToHttp().getRequest();
        const user = request.user;

        // Skip for unauthenticated routes (public endpoints)
        if (!user) return true;

        // Skip for superadmin users
        if (user.role === UserRole.SUPERADMIN) return true;

        // Check if user has at least one pet
        const petCount = await this.petService.countByUser(user.id);
        if (petCount === 0) {
          throw new ForbiddenException({
            error: {
              code: 'PET_REQUIRED',
              message: 'You must create a pet before using the app',
            },
          });
        }

        return true;
      }
    }
    ```

    Create a `@SkipPetCheck()` decorator:
    ```typescript
    export const SkipPetCheck = () => SetMetadata('SKIP_PET_CHECK', true);
    ```

    Apply `@SkipPetCheck()` to:
    - All auth routes (the entire AuthController class)
    - `POST /v1/pets` (pet creation -- the user is creating their first pet)
    - All subscription routes (SubscriptionController -- user may need to subscribe before/during pet creation)
    - `GET /v1/users/me` (user profile -- needed for onboarding flow)
    - Health check endpoint
